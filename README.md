# SMARTA — медиапортал

Статическая адаптивная вёрстка на HTML, CSS и JavaScript. Подготовлены версии для компьютеров, планшетов и телефонов. Сборка и установка зависимостей для просмотра не нужны.

## Страницы

- [mediaportal.html](mediaportal.html) — главная медиапортала.
- [news.html](news.html) — список новостей.
- [news-detail.html](news-detail.html) — шаблон отдельной новости.
- [articles.html](articles.html) — список статей.
- [article-detail.html](article-detail.html) — шаблон отдельной статьи.

## Просмотр

Откройте mediaportal.html через локальный HTTP-сервер редактора. При открытии непосредственно с диска отдельные браузеры ограничивают внешние SVG-спрайты и буфер обмена. Для GitHub Pages стартовый адрес — /mediaportal.html; автоматическая стартовая страница index.html отсутствует по принятому именованию.

## Структура

- assets/css/base.css — базовые правила и доступность.
- assets/css/components.css — шрифты, цвета и общие компоненты.
- assets/css/pages.css — главная и оба списка, включая адаптив.
- assets/css/news-detail.css — новость и общие блоки детальных страниц.
- assets/css/article-detail.css — статья, содержание и таблица.
- assets/js/main.js — кнопка загрузки на главной.
- assets/js/media-list.js — фильтрация, подгрузка и пагинация списков.
- assets/js/news-data.js и articles-data.js — демонстрационные публикации.
- assets/js/news-detail.js — галерея, копирование, социальные ссылки и демонстрационные кнопки товаров.
- assets/js/article-detail.js — содержание статьи.
- assets/images, assets/icons, assets/fonts — локальные ресурсы.

Основные разделы HTML отмечены комментариями. Адаптив: телефон — до 768 px, планшет — от 768 до 1272 px, компьютер — от 1272 px.

## Интеграция

Списки используют 48 демонстрационных новостей и 30 статей, включая повторы для проверки подгрузки. Параметр id пока открывает один демонстрационный шаблон каждого типа. Корзина не отправляет заказ; часть документов и 3D-моделей ожидает подключения каталога. Общая шапка и подвал основного сайта, видео и файлы не входят в этот этап. Bootstrap.native не подключён: текущие взаимодействия реализованы обычным JavaScript.

## Подготовка к GitHub

Папка .local содержит личные материалы и исключена из Git. .gitignore также исключает настройки редакторов, секреты, временные файлы и результаты проверок. Перед первым коммитом проверьте список файлов командой git status. Исключения действуют для новых файлов; уже отслеживаемые файлы нужно отдельно убрать из индекса Git.

Для повторяемого оформления: `npx prettier@3.6.2 --write "*.html" "assets/css/*.css" "assets/js/*.js" README.md`.

### Названия классов

Классы именованных блоков повторяют слои Figma: `container`, `card-grid`, `card`, `card-media`, `card-body`, `card-content`, `card-head`, `card-footer`, `article-list`, `news-list`, `article-footer`, `news-footer`, `btn`, `pagination`. Для безымянных элементов, доступности и поведения страниц сохранены вспомогательные классы. Одинаковые имена в разных компонентах ограничены контекстом селекторов, чтобы карточки публикаций и товаров не влияли друг на друга.
