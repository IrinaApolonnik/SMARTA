# SMARTA — медиапортал

Обычная вёрстка на HTML, CSS и JavaScript. Сборка и установка пакетов не нужны.
Для просмотра откройте `mediaportal.html` через локальный сервер редактора.

## Где что менять

| Файл | Что в нём |
| --- | --- |
| mediaportal.html | Главная медиапортала |
| news.html | Страница списка новостей |
| news-detail.html | Шаблон отдельной новости |
| articles.html | Страница списка статей |
| article-detail.html | Шаблон отдельной статьи |
| assets/css/base.css | Базовые правила и клавиатурный фокус |
| assets/css/components.css | Общие элементы: шапка портала, карточки, кнопки, эффекты наведения |
| assets/css/pages.css | Главная, списки и отдельная статья: таблица, содержание и адаптив |
| assets/css/news-detail.css | Новость, галерея, товары и категории |
| assets/js/media-list.js | Фильтр, подгрузка карточек и номера страниц при прокрутке |
| assets/js/news-data.js | Тестовые данные списка новостей |
| assets/js/articles-data.js | Тестовые данные списка статей |
| assets/js/news-detail.js | Галерея, копирование ссылок и демонстрационные кнопки товаров |
| assets/js/article-detail.js | Раскрытие и подсветка содержания статьи |
| assets/images, icons, fonts | Изображения, иконки и шрифты |

HTML редактируется прямо в пяти страницах. Разделы отмечены комментариями.
У списков новостей и статей есть особенность: JavaScript обновляет карточки из
`news-data.js` и `articles-data.js`. Их тексты меняйте в этих файлах, а разметку
подгружаемой карточки — в функции `card()` файла `media-list.js`.
Начальная разметка карточек в HTML остаётся для просмотра без JavaScript.

Общие стили и скрипты используются на нескольких страницах. HTML небольших
повторяющихся блоков оставлен непосредственно в страницах ради простоты:
например, изменения товаров нужно внести и в новость, и в статью.

## Что пока демонстрационное

Списки содержат повторы для проверки подгрузки. Ссылки с разными `id` открывают
один шаблон новости или статьи. Корзина не отправляет заказ; документы, 3D и CMS
не подключены.

Шапка и подвал основного сайта, видео и файлы не входят в этот этап.
Полная проверка всех браузеров из ТЗ и интеграция каталога ещё нужны.

Главная обновлена по утверждённому макету 7070:35: баннер, пять новостей и три горизонтальные статьи. Шрифт Smarta сохранён по согласованию. Стили главной находятся в начале pages.css.

Меню баннера на главной прокручивает к разделам #news, #articles, #videos и #files. Ссылки «Все новости» и «Все статьи» открывают полные списки. Для видео и файлов пока добавлены небольшие временные блоки «Скоро». На внутренних страницах вместо баннера — компактная ссылка обратно в медиапортал и переходы между списками новостей и статей.
